ALMORAVID — QUICK REFERENCE TABLES
================================================================
Five lookup tables synthesizing rules content that the rulebook
spreads across multiple sections. Everything else from the
foldout (Sequence of Play, Battle/Storm procedures, sidebars)
is in the rulebook in equivalent form and not reproduced here.

TABLE 1 — FORCES  (rules 1.6, 4.4.2, 4.5.2)
================================================================
 
Each unit lists Strikes in four categories:
  Strikes               — always-available Battle Strikes
  Strikes by Capability — only if Lord has the matching Arts of
                          War capability card (Battle context)
  Strikes by Garrison   — automatic when defending in Storm; only
                          Men-at-Arms and Militia get these
  Storm Strikes         — what the unit Strikes at during a Storm
                          action (4.5.2), combining all sources
 
STORM RULE (4.5.2): A unit Strikes in Storm using its Battle
values, EXCEPT Javelins and Slingers reduce x1 → x1/2 in Storm
(the only general reduction the rules specify). When a unit's
Battle Melee differs from its Storm Melee (e.g., Knights), that
difference is shown explicitly on the foldout.
 
Notes column lists Arts of War cards (by number) that modify the
unit beyond Strikes (Protection or Lord-rating effects).
Card-number suffixes: (Cap) = bottom-half capability,
                      (Evt) = top-half event.

TABLE 2 — STRONGHOLDS  (rules 1.3.1, 4.5)
================================================================
 
Garrison units strike at x1/2 (the standard missile rate).
Garrison Men-at-Arms with Crossbows: −1 vs Armor; the firing
side selects which enemy unit takes the Hit.
 
Type     | Cap | Val | Walls | Garrison                          | Surr  | Spoils*
---------+-----+-----+-------+-----------------------------------+-------+--------------------
City     |  3  |  3  |  1-4  | 3 Men-at-Arms (Crossbows)         | 3 dc  | Conquered marker;
(Gardens)|     |     |       |   + 3 Militia (Bowmen)            |       |  Coin x2, Loot x2,
         |     |     |       |                                   |       |  Prov x4
---------+-----+-----+-------+-----------------------------------+-------+--------------------
Fortress |  2  |  2  |  1-4  | 3 Men-at-Arms (Crossbows)         | 2 dc  | Conquered marker;
(Gardens)|     |     |       |   + 1 Militia (Bowmen)            |       |  Coin, Loot, Prov x3
---------+-----+-----+-------+-----------------------------------+-------+--------------------
Town     |  2  |  1  |  1-4  | 2 Men-at-Arms (Crossbows)         | 1 die | Conquered marker;
         |     |     |       |   + 1 Militia (Bowmen)            |       |  Coin, Prov x2
---------+-----+-----+-------+-----------------------------------+-------+--------------------
Castle   |  1  |  1  |  1-4  | 1 Man-at-Arms (Crossbows)         | 1 die | Conquered marker;
         |     |     |       |   + 1 Militia (Bowmen)            |       |  Coin, Prov
 
  * Cap (Capacity, 4.5.1): Lords needed for Siegeworks;
    also Capacity for Reposition during Storm.
  * Val (Stronghold Value, 1.3.1): number of Conquered or
    Jihad markers placed on Conquest. Each Conquered marker
    is 1 VP; each Jihad marker is 1/2 VP. Also = Surrender
    dice rolled (4.5.1).
  * Walls 1-4: Targeted side rolls 1 die per Hit; each roll
    within range (1-4) cancels 1 Hit.
  * Cities and Fortresses have Gardens (4.7.1).
  * Spoils shown only if Sacked (4.5.2); not awarded if
    Surrendered (4.5.1).
  * Garrison Militia are regular Bowmen — they do NOT get
    the −1 vs Armor or target-selection benefits that
    Garrison Men-at-Arms with Crossbows have.

TABLE 5 — ADJUST STATUS  (rule 1.4.3)
================================================================
 
INDEPENDENT → PARIAS
  - Christians add Coin equal to Service of Disbanded Taifa Lord.
  - Muslim Lord at Muslim Stronghold that would go Neutral:
    add Jihad (Conquer them).
  - Christian Lord at Muslim Stronghold that would go Neutral:
    either remove Siege/Bypass OR add Jihad (markers = value).
 
INDEPENDENT → RECONQUISTA
  - Flip all yellow Ravaged in Taifa to green.
  - Muslim Lord at Muslim Stronghold that would go Christian:
    add Jihad.
  - Christian Lord at Muslim Stronghold that goes Christian:
    remove Siege/Bypass.
 
PARIAS → INDEPENDENT
  - Flip all green Ravaged in Taifa to yellow.
  - Christian Lord at Neutral Stronghold that would go Muslim:
    Conquer them.
 
PARIAS → RECONQUISTA
  - Flip all yellow Ravaged in Taifa to green.
  - Muslim Lord at Neutral Stronghold that would go Christian:
    add Jihad.
 
RECONQUISTA → INDEPENDENT
  - Flip all green Ravaged in Taifa to yellow.
  - Christian Lord at Christian Stronghold that would go Muslim:
    Conquer them.
  - Muslim Lord at Christian Stronghold that goes Muslim:
    remove Siege/Bypass.
 
RECONQUISTA → PARIAS
  - Christian Lord at Christian Stronghold that would go Neutral:
    Conquer them.
  - Muslim Lord at Christian Stronghold that would go Neutral:
    either remove Siege/Bypass OR add Christian Conquered
    (equal to value).
